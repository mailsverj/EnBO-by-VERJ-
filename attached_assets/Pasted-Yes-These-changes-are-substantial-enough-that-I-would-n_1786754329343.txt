11. AUTOMATIC SOLAR DESIGN LOGIC

The design calculator should automatically calculate a preliminary system based on the submitted load.

Inverter Selection

Use the following progression:

Total Load	Default Inverter
1–500W	4kW
501–3,000W	6kW
3,001–6,000W	12kW
6,001–12,000W	24kW
12,001–24,000W	48kW
24,001–48,000W	96kW

PV capacity can force the system into the next inverter tier.

For example:

* If the calculated load requires a 4kW inverter but PV requirement exceeds 4kW → move to 6kW.
* If the system requires 6kW but PV requirement exceeds 6kW → move to 12kW.
* If the system requires 12kW but PV requirement exceeds 12kW → move to 24kW.
* If the system requires 24kW but PV requirement exceeds 24kW → move to 48kW.
* If the system requires 48kW but PV requirement exceeds 48kW → move to 96kW.

Continue this progression using the same principle for larger systems.

Inventory Matching

If the calculated inverter size does not exist in Inventory, select the nearest available inverter provided the difference does not exceed 5kW from the intended capacity.

Example:

Required:

48kW

Inventory:

* 45kW
* 50kW
* 60kW

Select:

50kW

because it is the closest suitable option within the permitted 5kW difference.

If no suitable inverter exists within the 5kW tolerance, flag the design for technical/manual review instead of automatically selecting an unsuitable inverter.

12. BATTERY SIZING FORMULA

Use:

Battery Required = Load (W) × Backup/Running Hours × 1.25

The 1.25 factor is intended to account for:

* Depth of discharge considerations
* Approximately 5% system inefficiency

The system should clearly display the calculated battery energy requirement.

Then match it against available battery products in Inventory.

Engineers can modify the automatically selected battery.

⸻

13. PV SIZING FORMULA

Use:

PV Required = [(Total Battery Size ÷ 6 hours) + Total Load] × 1.67

The 6 hours represents the assumed daily sunlight/solar generation window.

The 1.67 factor accounts for approximately 40% inefficiency/system losses.

The calculator should display:

* Calculated PV requirement
* Recommended PV capacity
* Selected panel size
* Number of panels
* Total installed PV capacity

Engineers must be able to manually modify the panel selection and quantity.
