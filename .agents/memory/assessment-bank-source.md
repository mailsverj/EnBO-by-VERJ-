name: Assessment bank source
description: Source-of-truth and scoring decision for the BDO assessment question bank.
---

The BDO assessment question bank must use the owner-supplied assessment text with explicit answer keys, rather than the public Google Forms respondent link.

**Why:** Google Forms hides quiz answer keys from public respondent pages. The supplied source lists all 30 questions, options, and correct answers. Its 60% wording conflicts with the owner's explicit instruction to keep the platform's 70% pass mark.

**How to apply:** Keep the assessment at 70% unless the owner explicitly changes it. When replacing the question bank, invalidate saved browser drafts so selections from a prior bank cannot be scored against the new questions.
